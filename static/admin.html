About Moustique

Moustique is a lightweight MQTT-style pub/sub broker that uses HTTP for communication.

Key Features:

  • ✅ HTTP-based communication
  • ✅ Wildcard subscriptions (+, #)
  • ✅ Persistent message storage
  • ✅ Multi-tenant with user isolation
  • ✅ Built-in web administration
  • ✅ High performance with Go
